# RatMath homepage

A single static page (`index.html`) introducing RatMath LLC and linking to every
RatMath app, tool, and paper. No build step: serve the folder with any static
server, for example `python3 -m http.server 8000`, or publish it with GitHub Pages.

Links that still need confirming are marked with `<!-- URL TO CONFIRM -->`
comments in `index.html` (RatMath Worlds, RiX Notebook, RiXCel).

The hero's "Ask the oracle" demo narrows a rational interval around √2, φ or √3
by taking mediants and asking exact integer questions, the same idea as the
Stern–Brocot tree.
