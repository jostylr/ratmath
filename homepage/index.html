Exact mathematics, from fractions up

Every real number, pinned down by intervals you can write as fractions.

RatMath builds mathematics on exact rational numbers. A real number is an oracle: ask it whether it lies in an interval between two fractions, and it answers. On that idea we have built a programming language, a calculator, notebooks, spreadsheets and explorable worlds, all of which tell you exactly how much they know.

Try RiX in your browser → Start the tutorials

The idea

Arithmetic that never rounds behind your back.

Floating point quietly turns 1/3 into 0.333…3 and moves on. RatMath keeps 1/3 as 1/3. When a value can't be written exactly, like √2 or π, it is carried as a rational interval that is guaranteed to contain it, and you can ask for a tighter one whenever you need it.

Comparisons are honest too. If two enclosures overlap, the answer is undecided rather than a guess, and the program can choose to refine or to branch.

A taste of RiXLanguage at a glance →
1/3 + 1/6;          ## 1/2, exactly
0.#3;               ## repeating decimal: 1/3
3.~7~15~1;          ## continued fraction: 355/113
2:5;                ## the rational interval from 2 to 5
decision := 23.456? < 23.4565;
decision ?: "yes" ?_ "no" ?? "needs refinement";

Get involved

Ways to work with RatMath

RatMath LLC develops these tools in the open. However you use mathematics, there is a way in.

  • Students

    Work through the tutorials in any browser, then keep going in RatCalc. Nothing to install.

  • Teachers

    Build lessons in RiX Notebook with live sliders and exact answers, and publish them as plain web pages for your class.

  • Developers

    Add exact arithmetic to an app with RatMath Core, or embed the full RiX evaluator and its plugins.

  • Researchers

    Read and critique the oracle papers, and test the ideas computationally in RiX.

  • Everyone

    Found a bug or have an idea? Open an issue on GitHub. Feedback shapes what gets built next.
